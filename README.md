# Kaggle-March-Madness-2025-Mania
Created a neural network to predict the tournament results of March Madness 2025. The model uses mean advanced stat differential for the regular season, cumulative mean advanced stat differential for a teams tournament performance, and a difference vector from the histogram of head to head coaching matchups with every coach in the NCAA as inputs. We pass each of these through a branch that consists of 2 layers of a Linear layer followed by a ReLU layer. Then we concatenate the results and pass it through one more layer that uses a Linear followed by a ReLU and a Linear followed by a signmoid. I then trained this on all regular season games from before the 2025 season and finetuned on all tournament games from before the 2013 season. Then I validated on tournament data from between 2013 and 2019 and tested on all tournament games after 2019. The results gave me between 60% and 70% accuracy on numerous test runs, but working on finding better hyperparameters or architecture for future years.
